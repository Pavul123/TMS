8. Most important functional separation
For development, I would structure the application around three major user experiences, even though the RBAC contains more roles:
🟤 Management Portal
MD
Manager / Assistant Manager
Main focus:
Dashboard + Operations + Reports

🟤 Accounts Portal
Accounts
Main focus:
Invoices + Payments + Ledgers + Expenses + Cash/Bank

🟤 Operations/Data Entry Portal
Operations Manager
Worker
Main focus:
Trips + Vehicles + Drivers + Delivery

Admin Control Center
Admin
Main focus:
Users + RBAC + Masters + Imports + Settings + Audit
So the actual system architecture becomes:
                    TMS
                     │
       ┌─────────────┼─────────────┐
       ↓             ↓             ↓
    MANAGEMENT     ACCOUNTS     OPERATIONS
       │             │             │
    MD/Manager     Accounts     Ops Manager
                                  Worker
       │             │             │
       └─────────────┼─────────────┘
                     ↓
              CENTRAL DATABASE
                     │
              PostgreSQL
                     │
             Audit + Ledger
